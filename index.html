Customer support

Kya iPhone mein download hoga?

Nahi. Abhi ye app sirf Android phone ke liye hai. iPhone (iOS) mein download ya install nahi hoga.

App install nahi ho raha, kya karein?

Pehle file dobara download karein. Phone puchhe to "Is source se install karne ki anumati" dein. App Android 5.0 ya usse upar par chalta hai. "Problem while parsing the package" aaye to purani adhuri file delete karke naya download karein.

Entry fees kaise bharein?

App mein Add Money se wallet mein paisa daalein, phir apna match chunkar Pay & Join dabayein.

Room ID aur Password kab milega?

Entry fees bharne ke baad app mein match ke Room ID & Pass button par milega. Bina entry fees ke Room ID nahi dikhega.

Jeeta hua prize kaise milega?

Match ke baad admin kills aur rank confirm karta hai, aur prize seedha aapke wallet mein jud jaata hai. Wahan se Withdraw kar sakte hain.

Paisa wallet mein nahi aaya to?

App ke Messages section mein admin ko apna UID, match ka naam aur payment ka screenshot bhejein. Jaanch ke baad theek kar diya jayega.

Kya ye app free hai?

Haan, app download karna bilkul free hai. Sirf match join karne par entry fees lagti hai.
